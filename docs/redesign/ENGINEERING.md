## Implemented reference profiles

The Electrical engineering dialog provides one undoable apply for regional inputs, conductor conditions, exact end hardware, protection data, chassis PE terminals, source neutral bonds, earthing assumptions and directional battery limits. Optional fields preserve older projects. Settings and end schedules are exported in CSV.

- ZA: [Aberdare Facts & Figures 2025](https://www.aberdare.co.za/wp-content/uploads/Facts-Figures-English-2025.pdf), printed pages 37–45. PVC SWA 3/4-core copper/aluminium, shaded air, buried duct and direct-buried ratings. Air baseline 30 °C; soil baseline 25 °C, thermal resistivity 1.2 K·m/W, 500 mm depth. Supported temperature/grouping tables round to the next conservative tabulated condition. Grouped ducts, other soils/depths, solar exposure and loaded-neutral harmonics remain unresolved.
- GB: [Eland's BS 7671:2018 table 4D1A reproduction](https://www.elandcables.com/media/vyrp3kxq/table-4d1a-and-4d1b.pdf), 70 °C single-core copper, methods B and C, two/three loaded conductors, with [Schneider's IEC ambient and bunched-group factors](https://www.electrical-installation.org/enwiki/General_method_for_cable_sizing). The current [IET edition is A4:2026](https://electrical.theiet.org/bs-7671-18th-edition-wiring-regulations/ensure-you-are-up-to-date-with-bs-7671); changes in that edition have not been checked against a licensed full text. The UI labels the exact implemented reference edition.
- US: [Southwire MC installation guide](https://www.southwire.com/medias/sys_master/installation-manuals/installation-manuals/hca/hff/8887676010526/MC-Installation-Guide-Southwire.pdf), printed 29–30, NEC 2017 table 310.15(B)(16), native 14 AWG–4/0 sizes, copper/aluminium, 60/75/90 °C columns, ambient/grouping factors, separate terminal-temperature cap, small-conductor OCP limits and optional 125% continuous-load criterion. [Southwire grouping reference](https://www.southwire.com/medias/Re3-E8-V2Technical-Reference-Lead-Wire-Maximum-Current-Capacity-HIGHRES.pdf). Arbitrary metric sizes are not silently treated as listed AWG. Confirm locally adopted editions and applicable exceptions separately.

The designer keeps voltage-drop sizing and then raises conductor size to meet saved regional ampacity/protection assumptions. Physical building refits repeat both constraints. Unsupported sizes/conditions produce an explicit error rather than extrapolation. Sandbox diagnostics compare design and solved current against allowable current and assigned protection. Source protection assignments require review for multiple feeds and bypasses; a selected device alone does not prove fault isolation.

## Protection and earthing boundaries

Checks include Ib/In/Iz, an entered IEC conventional-trip multiplier, interrupt capacity against the configured prospective fault current, adjacent AC/DC rating mismatch, PVC multi-core cable I²t withstand, and exact manufacturer-pair selectivity limits when supplied. Protection simulation remains the labelled generic time curve; entered manufacturer data supports design checks and does not fabricate a complete trip curve. A global earth-fault current is an input assumption, not a calculated worst-case short-circuit study. Different source domains need separate studies.

TN uses entered Zs × Ia ≤ U0; TT uses Ra × IΔn ≤ entered touch-voltage criterion. IT monitoring/second-fault protection remains an explicit unresolved finding. The UI exposes optional real chassis PE ports and ordinary conductors to earth-reference components; declared source bonds insert neutral–PE resistance into the circuit. Missing chassis connections and missing/multiple connected source bonds are reported. This does not infer double-insulated construction or establish measured installation continuity. [Schneider PE guidance](https://www.electrical-installation.org/enwiki/Sizing_of_protective_earthing_conductor) supplies the adiabatic method; the user must supply a suitable k and verified fault clearing data. US EGC sizes use Southwire's reproduced NEC 2017 table 250.122. Minimum mechanical sizes, electrode conductor sizing, PEN conductors, RCD type/time, transfer-source bonding, and neutral harmonics still require a separate assessment.

## Terminations and battery management

Exact sourced end options include [Klauke R-series class-2 copper lugs](https://www.klauke.com/gb/en/tubular-cable-lugs-cu-standard-type-4957), 6–240 mm² with listed M6/M8/M10 variants, and [Stäubli MC4-Evo 2A 32.0316–32.0321P0001](https://www.staubli.com/content/dam/ecs/catalogs-brochures/RE/SOL-MC4-Evo-2-11014101-en.pdf), listed 4/6 mm² or 12/10 AWG contacts and cable outer-diameter variants. Checks require the actual conductor class, stud, connector family/gender, current and outer diameter. A generic “MC4 compatible” label does not establish an exact match. Tooling, torque, certification/listing, terminal thermal ratings and contact geometry are still installation checks; an unresolved end remains labelled in CSV.

Optional BMS equivalents independently cap charge/discharge current and inhibit each direction for temperature/SOC/external-control conditions. Low/high terminal voltage latches the respective direction off at the next retained simulation segment; reset simulation clears these latches. These are bounded pack equivalents, not cell-balancing, chemistry or contactor firmware. External-control batteries require the declared BMS connection. Catalogue-sourced limits are populated in section 6. MPPT startup/run thresholds use sourced fields where present, with a 0.25 V numerical ramp and retained tracking state; other tracking/taper behaviour remains generic.
